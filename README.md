# 🌳 WGIF — Welcome, Grafted Into the Fam!

Ранее: «extension Welcome Familio» (EWF). Теперь название расширения — **Welcome, Grafted Into the Fam**, сокращённо **WGIF**.

- Welcome — Добро пожаловать
- Grafted — Привитые (как родная ветвь к древу)
- Into the — В состав
- Fam — Нашей семьи

> Welcome, Grafted Into the Fam! (Добро пожаловать, привитые к нашей семье!)
> «No branch is lost forever. Connected by blood, united by history, grafted back home.» — Ни одна ветвь не потеряна навсегда. Связаны кровью, объединены историей, привиты обратно домой.
> «Bound by blood, strengthened by choice» — Связаны кровью, укреплены выбором. «Rooted in the past, growing for the future» — Укоренены в прошлом, растём ради будущего.

Расширение Chrome для сбора людей и семейных связей с familio.org (проект «Welcome Familio», WF).

Установка: chrome://extensions → «Режим разработчика» → «Загрузить распакованное» → эта папка.
Запуск: откройте familio.org, войдите в аккаунт, нажмите значок расширения.

Режимы: 1 аккаунт («Люди»), 2 персона со связями, 3 фамилия, 4 автосбор из файла ссылок .html.
Результат: Excel и/или GEDCOM (замена / дополнение / с подтверждением / новый файл). Оригинал GEDCOM всегда копируется
в рабочую папку «имя_ГГГГ-ММ-ДД». При любой правке записи обновляется метка времени (`CHAN` → `DATE`/`TIME`). Есть «Пауза» и «Стоп».

Охват: только текущая персона / все предки (всех или только мужчин) / все потомки (всех или только мужчин).
Разделы карточки: Отец, Мать, Супруги, Дети, События, Родственники, Обсуждение. Персоны с пометкой «Скрытая персона» пропускаются.
Иконка: icons/ (из icon.png).

Разработчики и создатели: Мр. Фомка (Mr. Crowby) и Мастер Добрых дел — «Фомка добрых дел» (Crowbar of Goodness).
Репозиторий: Public.

Настроено по реальному familio.org (проверено на одной персоне без родственников): карточка `/persons/<uuid>`, вкладки `?tab=0` (События) и `?tab=1` (Родственники),
список «Мои люди» `/profile/my-persons`. Разметку связей (ссылки на родственников) и пометку «Скрытая персона» нужно ещё проверить на дереве с данными.

Статус 0.3.0: каркас и логика готовы, GEDCOM-слияние и Excel проверены тестами (`node tests/run.js`).
Правила разбора страниц сайта — эвристические (extract.js, поле «Настройки сайта»); их нужно подогнать по реальной вёрстке familio.org.

## Имена (0.4.0)
Родственники на странице — ссылки, имя в тексте ссылки: «Фамилия Имя Отчество». Если фамилия женщины с фамилией в скобках («Иванова (Жегалова) Мария Федоровна») — в скобках девичья.
В GEDCOM: основное имя по девичьей фамилии (`TYPE birth`), второе — по фамилии в браке (`TYPE married`); поиск совпадений идёт по любой из двух. В Excel — столбец «Девичья фамилия».

## Два типа страниц (0.5.0)
**Аккаунт персоны** (`/users/<id>`): сбор списка под заголовком «Люди, добавленные пользователем», страницы по 10 персон
(`?tab=1&page-userPersons=N`, до конца списка); по каждой ссылке — переход на страницу персоны. Список аккаунта — лишь часть ветки;
вся семья собирается после обхода страниц персон (охват «0. Вся родовая ветка»).
**Страница персоны** (`/persons/<id>`): шапка и правый технический сектор не собираются. Слева — фото и сводка; ниже — таблица семьи
со столбцами «статус», «Фамилия Имя Отчество», «Дата рождения», «Место рождения», «Дата смерти», «Место смерти» (и «Место жительства»).
Ссылки мест собираются, но по ним не переходят. Таблица попадает в лист Excel «Семья».
Фамилия в скобках: у женщин — девичья, у мужчин — фамилия до смены (в GEDCOM второе имя `TYPE aka`).
Иконка расширения — из Icon2.jpg.

## 0.7.0-test — ручное указание секторов
Единственный режим: «Страница персоны» (все члены семьи указанной персоны). Разделы: События, Родственники; «Обсуждение» не обрабатывается.
Сектора указываются мышью (↑/↓ — крупнее/мельче, Esc — отмена): разделы, названия столбцов «События», названия столбцов «Родственники», ФИО персоны, состав семьи, сводная информация/фото. Результат — карточки семей без дублей людей; перешедшие из другой семьи помечаются.
