# extension Welcome Familio (EWF)
Расширение Chrome для сбора людей и семейных связей с familio.org (проект «Welcome Familio», WF).

Установка: chrome://extensions → «Режим разработчика» → «Загрузить распакованное» → эта папка.
Запуск: откройте familio.org, войдите в аккаунт, нажмите значок расширения.

Режимы: 1 аккаунт («Люди»), 2 персона со связями, 3 фамилия, 4 автосбор из файла ссылок .html.
Результат: Excel и/или GEDCOM (замена / дополнение / с подтверждением / новый файл). Оригинал GEDCOM всегда копируется
в рабочую папку «имя_ГГГГ-ММ-ДД». При любой правке записи обновляется метка времени (`CHAN` → `DATE`/`TIME`). Есть «Пауза» и «Стоп».

Статус 0.1.0: каркас и логика готовы, GEDCOM-слияние и Excel проверены тестами (`node tests/run.js`).
Правила разбора страниц сайта — эвристические (extract.js, поле «Настройки сайта»); их нужно подогнать по реальной вёрстке familio.org.
